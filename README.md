## 🔭 About Me

- 🛠️ SRE focused on **observability**: making systems tell you what is wrong before users do.
- 📡 I build **OpenTelemetry** pipelines on Kubernetes: agents, collectors and gateways for metrics, logs and traces.
- 🧪 I learn by breaking things on purpose: chaos tests, outages and recovery, measured with real numbers.
- 🔁 I came from web development, so I see reliability from the app side too.
- ✍️ I share what I learn as **hands-on incident labs** you can run on your laptop.
